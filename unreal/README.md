# unreal/

Placeholder for the future Unreal desktop prototype.

**No Unreal project files live here yet.** This directory currently
holds only this README plus, eventually, a thin C++ module under
`HHGXRLab/` that loads `data/samples/demo_bundle_minimal/manifest.json`
and renders the four core panels described in
[`docs/UNREAL_IMPORT.md`](../docs/UNREAL_IMPORT.md).

## Why empty for now

The Phase 0 deliverable in [`docs/ROADMAP.md`](../docs/ROADMAP.md) is a
clean data pipeline, not a working Unreal viewer. Committing a generated
Unreal project (`Binaries/`, `DerivedDataCache/`, `Intermediate/`,
`Saved/`, `*.uasset`) before the data pipeline is stable would:

- bloat the repository with autogenerated content,
- risk leaking `Build.cs` or local paths,
- create rebase friction for any data-pipeline iteration.

When the Phase 1 prototype starts, the project will be created under
`unreal/HHGXRLab/` and the relevant ignore rules are already in the
top-level `.gitignore` (`Binaries/`, `DerivedDataCache/`, `Intermediate/`,
`Saved/`, `*.uasset`, `*.umap`, ...).

## Target behavior

See [`docs/UNREAL_IMPORT.md`](../docs/UNREAL_IMPORT.md) for the full
spec. Short version:

1. Open `manifest.json`, verify schema id.
2. Read `data_small.json` arrays.
3. Render four panels: band path, E(t), J(t), HHG spectrum.
4. Render a 3D `UProceduralMeshComponent` for the band surface.
5. Show a persistent provenance badge.
6. Disable any panel listed in `manifest.missing_modules`.
